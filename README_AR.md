# ترجمها v2 — ترجمة المقال من قائمة المشاركة

نسخة PWA عربية للجوال. عند اختيار «ترجمها» من قائمة مشاركة أندرويد:
- تستقبل النص إذا كان التطبيق المشارك يرسله.
- إذا وصل الرابط فقط، تحاول استخراج نص المقال تلقائيًا عبر Jina Reader، ثم تترجمه تلقائيًا إذا كان مفتاح NanoGPT والموديل محفوظين.
- إذا تعذر الاستخراج، تظهر رسالة توضح ذلك ويمكنك إعادة المحاولة أو نسخ النص يدويًا.
- تدعم ترجمة أمينة مبسطة، ترجمة أقرب للأصل، وشرحًا للمبتدئ.

## التثبيت والنشر مجانًا عبر GitHub Pages
1. أنشئ مستودع GitHub عام أو افتح المستودع الذي استخدمته سابقًا.
2. ارفع **كل الملفات** الموجودة في هذه الحزمة إلى جذر المستودع، مع استبدال النسخ القديمة.
3. من Settings → Pages اختر Deploy from a branch، ثم `main` والمجلد `/(root)` واحفظ.
4. افتح رابط GitHub Pages في Chrome على الجوال وانتظر حتى يُحمّل الموقع الجديد.
5. إذا كان التطبيق مثبتًا سابقًا، **احذفه من الشاشة الرئيسية أولًا** ثم افتح الموقع في Chrome وثبّته مجددًا عبر قائمة Chrome → Install app. هذا يجبر أندرويد على إعادة قراءة إعدادات المشاركة والأيقونات.
6. افتح «ترجمها» واضبط مفتاح NanoGPT والموديل وطريقة الترجمة، ثم اضغط «حفظ الإعدادات».
7. جرّب: افتح المقال في Chrome أو Feedly → مشاركة → اختر «ترجمها». عند وصول رابط فقط، تحاول الأداة جلب نص المقال ثم ترجمته تلقائيًا إذا كانت الإعدادات محفوظة.

## إعداد NanoGPT
- أدخل مفتاح الاشتراك/API في الحقل المخصص.
- اضغط «تحميل موديلات الاشتراك» واختر موديلًا مشمولًا في اشتراكك، أو أدخل Model ID يدويًا.
- اضغط «حفظ الإعدادات».

## حدود وخصوصية
- استخراج الرابط يستخدم `https://r.jina.ai/`، وهي خدمة خارجية تحاول جلب المحتوى العام وتحويله إلى نص. الرابط يُرسل إلى الخدمة كي تجلب الصفحة؛ لا يُرسل إليها مفتاح NanoGPT. بعدها يُرسل نص المقال المستخرج إلى NanoGPT للترجمة.
- خدمة القراءة توفر استخدامًا أساسيًا مجانيًا بحسب وثائقها الحالية، مع حدود للطلبات قد تتغير. لا تحتاج الأداة إلى استضافة مدفوعة جديدة لهذا الاستخراج.
- بعض المواقع تمنع القراءة الآلية أو تحتاج تسجيل دخول/اشتراك، لذلك لا يمكن ضمان استخراج كل صفحة، خصوصًا المقالات خلف جدار دفع أو صفحات خاصة.
- إذا كان التطبيق المصدر يشارك نص المقال نفسه، تستخدم الأداة النص الذي وصلها بدل جلب الصفحة من جديد.
- مفتاح NanoGPT يبقى في تخزين المتصفح على هذا الجهاز. لا تنشره في مستودع GitHub أو أي ملف عام.
- نسخة PWA تدخل إليها من قائمة المشاركة، وليست زرًا عائمًا فوق كل تطبيق.
- لم أتمكن من اختبار الاتصال الحي مع Jina Reader أو NanoGPT من بيئة البناء؛ إذا ظهرت رسالة CORS أو خطأ API بعد النشر، أرسل لقطة للخطأ لنحدد السبب بدل تخمينه.
